# Pixera Glossary

- **Canvas / Canvas Resolution** — the 2D render surface and its pixel resolution; set per Screen, should match projector output.
- **Screen** — virtual representation of a physical display/surface (size in metres + Canvas Resolution).
- **Screen Group** — container organising multiple screens; controls layer visibility/animation across configs.
- **Layer** — content container on the Timeline; bound to a **Home Screen**.
- **Home Screen** — the reference screen a layer originates on.
- **Timeline** — sequences layers; holds clips, keyframes, **cues**.
- **Cue** — timeline marker performing an operation (Play/Pause/Stop/Jump/Trigger).
- **Compound** — API namespace addressing timelines/cues by name or index (no handles needed).
- **Mapping** — mode for projectors, feed areas, warp, soft edge, calibration.
- **Feed Area** — automatic division of screen space across projectors.
- **Feed Mode** — how the feed maps to the screen: None / Fit / Stretch / Pixel Accurate / Perspective.
- **FFD (Free-Form Deformer)** — preferred warp; draggable control-point grid.
- **Vertex Modifier** — warp by editing a 3D model's own vertices.
- **Polygonal Warp** — non-rectangular feed editing (Pixel-Accurate feed).
- **Multi-Pos Warp** — per-viewpoint warps blended for tracked cameras (virtual production).
- **Soft Edge / Softedge** — blended overlap between projectors; static or **Dynamic** (3D/moving).
- **Marker Calibration** — point-correspondence (PnP) projector pose solve from user-placed markers.
- **Re-Projection Error** — average marker misalignment after a solve; target < 1 px @ HD.
- **VIOSO** — camera-based structured-light auto-calibration integrated with Pixera.
- **MPCDI** — VESA interchange format for warp/blend/geometry; importable, not generated by Pixera.
- **UV map** — 2D unwrap of a 3D surface for texture/video mapping.
- **Handle** — opaque id for an API object (screen/projector/…); invalid after project reload.
- **0xPX** — the literal four ASCII chars delimiting JSON/TCP(dl) messages.
- **VQI (Visibility Quality Index)** — this server's 0–1 score of how calibratable a mesh is from a projector.
